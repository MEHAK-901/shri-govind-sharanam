# shri-govind-sharanam
Shri Govind Sharanam — a small, lovingly built Gita reader focused on calm, intentional reading.
This repo is a snapshot of days of careful UI polish. The experience is minimal, meditative, and designed to be stable so judges and reviewers can run or deploy the app quickly.
Big Idea
Problem
Modern reading apps push features, notifications, and friction that fragment attention and dilute contemplative reading.

Solution
Provide a lightweight, distraction‑free Gita reader that combines clear typography, subtle microinteractions, and a few purposeful features (read‑aloud, random discovery, private reflections) so users can enter a calm reading state quickly.

Core Principles
Simplicity — only the controls you need, nothing more.

Respect for text — typography and spacing designed to make reading restful.

Serendipity — a Random Page Game to invite new perspectives.

Privacy by default — reflections stored locally unless the user chooses otherwise.

Easy deployability — static dist ready for Cloud Run, Netlify, or Vercel.

Impact
Help users turn short moments into meaningful practice: a 5‑minute session becomes a ritual, not a checklist. The app nudges curiosity and reflection without demanding attention.

How it shows up in the product
Read Aloud for accessibility and meditative listening.

Random Page Game to spark unexpected insight.

Reflection Journal to capture personal responses tied to verses.

Polished UI that preserves the feel you spent days crafting.

One‑line Vision
A calm companion for the Gita — minimal, respectful, and designed to make every verse feel like a small, quiet ceremony.
